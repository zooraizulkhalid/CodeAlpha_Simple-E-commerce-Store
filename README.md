
# VOID District — E-Commerce Website

A modern, responsive streetwear e-commerce website developed as part of the CodeAlpha Web Development Internship.

VOID District provides an interactive online shopping experience where users can explore products, save favourites, manage their shopping cart, and complete a demo checkout.

## Features

- Responsive homepage with featured products
- Product catalogue with search and filtering
- Category, size, and price filters
- Product sorting functionality
- Individual product detail pages
- Product size and quantity selection
- Wishlist with add and remove functionality
- Interactive shopping cart drawer
- Cart quantity management and removal
- Demo checkout with shipping calculations
- Discount coupon support (VOID10)
- Cash on Delivery demo order confirmation
- LocalStorage-based cart and wishlist persistence
- Responsive layouts for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage
- Git and GitHub
- Visual Studio Code

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/zooraizulkhalid/CodeAlpha_Simple-E-commerce-Store.git
   ```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension if it is not already installed.

4. Open `FrontEnd/index.html`.

5. Right-click and select **Open with Live Server**.

6. Explore the website in your browser.

## Important Notes

This project currently operates as a frontend demonstration.

- Checkout does not process real payments.
- Demo orders are not submitted to a production backend.
- Cart and wishlist information is stored locally in the browser.
- Newsletter registration is a demonstration feature.
- Shipping rates are sample values for demonstration purposes.
